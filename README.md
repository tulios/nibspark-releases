# nibspark's Flatpak repository

Served by GitHub Pages at https://flatpak.nibspark.app/, made by the release workflow of
nibspark: each release replaces this branch. Install nibspark from it with

    flatpak install https://flatpak.nibspark.app/nibspark.flatpakref

and `flatpak update` keeps it up to date. See https://nibspark.app.
